在浏览器里跑真正的 Linux 发行版，没有后端。

展位

Alpine Linux 图形桌面

完整的 i3 窗口管理器跑在 Xorg 上，帧缓冲直接刷进 canvas。 CheerpX 把 x86 指令 JIT 成 WebAssembly，发行版本身一行代码没改。
Ubuntu / Arch / Rocky / Debian 待构建

用 container2wasm 把 Docker 官方镜像转成 wasm，走终端模式。 需要先装 Docker 并清理磁盘空间。

三条路的取舍

方案原理发行版速度许可
CheerpX x86 → WASM JIT Debian、Alpine最快 闭源，仅个人/开源免费
container2wasm Bochs / TinyEMU 解释 任意 Docker 镜像慢 Apache-2.0
linux-wasm 内核原生编译到 arch/wasm 仅 BusyBox无模拟开销 GPL，概念验证
为什么不能"把发行版编译成 WASM"
WASM 缺的不是性能而是 Linux ABI：没有 fork()、没有 MMU、没有信号、 没有 ELF 动态链接器。所以可行的路要么是把 CPU 模拟器编译成 WASM 让原版镜像跑在里面， 要么像 linux-wasm 那样改内核去迁就 WASM —— 代价是 fork 和 longjmp 直接不支持。
本地开发：npm run dev，必须带 COOP/COEP 响应头， 否则 SharedArrayBuffer 不可用、CheerpX 起不来。
